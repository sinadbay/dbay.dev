Why Splitzy

Split trip costs without the awkwardness

No spreadsheets, no IOU scribbles. Create a trip, share a code, add expenses, and get clear settlement instructions — in one app, in real time.

Features

Everything you need to split fairly

Built for real trips and real groups: secure auth, flexible splitting, and a settlement engine that minimizes how many payments you actually make.

Secure authentication

Email magic link sign-in with Supabase Auth. No passwords to remember, secure session management.

Trip management

Create trips with custom names and currencies. Generate unique 8-character share codes and join existing trips with a code.

Member management

Add placeholder names when creating a trip. Friends claim their name using the trip code with automatic owner/member roles.

Expense tracking

Add expenses with description and amount, choose who paid. Split equally or use custom weights for proportional splitting.

Smart settlement calculator

Automatically calculates who owes whom and optimizes to minimize the number of transactions. Real-time balances and clear settlement steps.

Real-time sync

All data in Supabase with real-time updates across devices. No local-only limits, automatic conflict resolution.

In-app reviews

Native review prompts (iOS & Android), smart timing, respects your choice. Re-prompt after 90 days if dismissed. Direct submission to stores.

How it works

Three steps to fair splits

1

Create a trip

Sign in, create a trip, set name and currency. Share the generated code with friends so they can join and claim their name.

2

Add expenses

Log who paid what and who’s in on each expense. Split equally or use custom weights. Everything stays in sync for the whole group.

3

Settle up

View optimized settlement instructions: who pays whom and how much. Fewer payments, no guesswork. Export to PDF if you like.

Settlement

Fewer payments, clear instructions

We minimize the number of transfers so settling up is simple.
